# 到港航班预计时间计算
[![Build Status](http://d2.int.it2000.com.cn/api/badges/thyia/estt-calc-kotlin/status.svg)](http://d2.int.it2000.com.cn/thyia/estt-calc-kotlin)



## 问题
旧的电报系统，查询航班历史的时候使用单一航班号为限制条件，因为同一个航班号的航班不同运营日执行的是不同飞行计划，导致航班历史查询不准确，影响预计时间的计算
## 解决方案

由于原有电报系统开发时间较早，难以在原有系统上增加复杂的方法，于是开发一个单独的服务程序，执行单一的飞行时长计算功能

## 算法

1. 首先查询已经激活的季度计划
2. 根据季度计划，航班的飞行日期，查询到符合运营日的季度计划航班
3. 从季度计划开始的日期，到目前航班日期查询航班历史，历史航班必须符合运营日条件，同时不能延误太长时间
4. 如果符合条件的历史航班数超过20（可配置），则计算平均飞行时长
5. 如果历史航班不足，则使用季度计划飞行时长
6. 如果无法找到季度计划，则不计算飞行时长

## 运行

程序可以使用docker运行，也可以直接运行

### 使用docker

镜像名称是： reg.int.it2000.com.cn/changde/estt-calc

### 直接运行

从releases下在版本以后直接运行 如果使用shadowjar版本是一个单一jar文件，使用java -jar直接运行 如果是jar分离的版本，解压以后，直接运行bin目录里的estt-calc脚本执行程序

### 参数配置

参数配置文件是application.yml文件，打包在estt-calc.jar文件中，也可以通过直接配置环境变量来设置

| 参数名称 | 参数含义 | 取值 |默认值|
| --------|---------|------|-----|
|ORACLE_HOST|数据库的主机名|可以是ip地址: 127.0.0.1， 也可以是主机名:bj024|bj024.int.it2000.com.cn
|ORACLE_PORT|数据库端口|通常是：1521 | 1521|
|ORACLE_SID| 数据库的SID|一般是 orcl|orcl|
|ORACLE_USER|数据库用户名|cdjc|cdjc|
|ORACLE_PASS|数据库的密码|cdjc|cdjc|
|MAX_DELAY|计算有效历史航班时候，航班最大的延误时间(分钟)|120(分钟)|120|
|MIN_HISTORY|求取飞行时长平均值的时候，最少的有效航班数，如果小于此值，则不做计算，直接用季度计划的飞行时长|20|20|

## 接口使用

1. 查询当前的飞行季度

GET /estt/season

2. 查询航班的季度计划

GET /estt/seasonal/航班号/航班日期

航班日期的格式：yyMMdd

如： /estt/seasonal/mu9941/210329, 查询2021年3月29日，mu9941的季度计划

3. 查询航班历史

GET /estt/history/航班号/航班日期

如： /estt/history/mu9941/210329, 查询2021年3月29日飞来的mu9941航班对应的历史飞行记录

4. 查询飞行时长（核心功能）

GET /estt/flyTime/航班号/航班日期

如：/estt/flyTime/mu9941/210329, 查询2021年3月29日飞来的mu9941航班的飞行时长
